# Spell Pets

A pixel-art spelling and Chinese-character game for kids.

- Play: https://eileending.github.io/spell-pets/
- Sign in with Google; progress is saved to the family's Firebase database (project `spellpet-c7eb0`).
- `firestore.rules` holds the database security rules (paste them into Firebase console → Firestore → Rules).
- `zhaudio/` holds the Chinese pronunciation clips.
